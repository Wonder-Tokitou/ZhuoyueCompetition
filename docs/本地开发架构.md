
## 本地运行

开发期 Vite 默认 :5174 将 /api、/media 代理至 FastAPI :8100；start.bat 会构建前端并由 FastAPI :8100 统一托管。不需要分别启动 AI 服务。端口和主机仍由本机配置决定，原始 case-sim 不修改。

启动按脚本位置定位项目根；backend/.env、backend/data、logs 保持原位。依赖已安装时不重复下载；更换电脑必须重新创建 .venv，不复制 Python 启动器。手动启动从根使用 backend.app.main:app，不再使用 app.main:app。

学生登录后直接看到已发布案例，令牌与二维码仍可选。开始推演时冻结教师案例版本；选项打乱只改变显示顺序，不改变策略 key 对应结果。学生提交读取对应已发布结果，文字只作为决策理由。

## AI 流程

- 案例：平台解析素材与取规则 → AI 生成/有限修复 → 平台确定性校验 → 草稿 → 教师校准与发布。
- 答疑：AI 规划受限工具 → 平台提供本人当前会话授权证据 → AI 回答并核验引用 → 平台归档；不读取未选结果。
- 复盘：完成三节点后排队 → 冻结证据 → AI 生成 → 动态完整性校验 → 独立上下文审核 → 有限修复 → 平台保存；教师版本优先。

复盘不限制分析项数或顺序，但不能缺少基础框架内容、正文或独立结论。内部 read_* 引用保存用于追溯，界面显示中文依据。

数据库任务支持查询、幂等提交与启动恢复。模型配置缺失时 AI 任务明确失败，不编造推演结果。云端 PostgreSQL/OSS 迁移后续进行；AI 核心没有数据库和文件路径依赖。
