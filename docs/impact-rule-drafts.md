# AI递进规则草稿

节点完整且尚无教师保存规则时，打开校准页会自动提交后台草稿任务。
AI读取原材料、教师已保存基准、9个选项、商科传导规范，提出5类影响系数。
展开每行可见依据、教学假设标记和限制；教师可逐项修改。人工修改后原AI依据会标注为旧依据。

现金基准金额不由AI编造。草稿检查27路径的营收、毛利率、费用及份额；现金金额待教师填写后，预览/保存/发布再完整检查。
校验内部现金占位0绝不写回表格或业务基准。净利润仍由确定性公式计算。

## 教师操作

保存上方基准 → 等待AI草稿 → 修改系数/补现金金额 → 预览 → 勾选确认 → 保存 → 发布。
已保存的教师规则（包括全0）不再自动生成或覆盖。生成期间人工改表，较晚的AI结果也不会覆盖当前输入。
AI失败会显示原因并允许重试；刷新页面恢复持久化任务，不会反复扣费生成。
同一案例内容与提示词版本复用同一任务；案例修改后的新任务使用新快照。

## 开发边界

- `ai_component/agents/impact_rules.py`：提示词与模型请求，无数据库依赖。
- `backend/app/integrations/ai/impact_rules.py`：任务幂等、程序校验、制品记录和人工优先检查。
- `task_runner.py`：复用持久化异步执行、有限重试与重启恢复。
- `POST /api/cases/{id}/simulation/suggest`：教师鉴权，返回任务；retry=true仅重试失败任务。
- 现有 `/api/ai-tasks/{id}` 与 `/output`：进度及建议读取。
- `ProgressivePanel.tsx`：自动填表、逐条依据、修改保护；不会自动保存或发布。

任务草稿存AiTask与AiArtifact，教师权威规则存SimulationConfig；两个存储位置不能混用。
教师保存后AI仅归档候选稿，不写SimulationConfig；旧学生会话、已发布快照与学生确定性计算不变。
