# AI 展示、后台生成与调用优化（2026-09-25）

## 使用方法

重启本目录的 `start.bat` 后刷新浏览器。前端构建已更新；无需重新安装依赖，原始 `case-sim` 和真实 `.env` 未修改。

- 助教回答与引用依据分开显示，点击“查看引用依据与决策数据”展开。依据中的指标、策略和决策前后值使用中文标签；旧消息在读取时转换，不重写数据库历史；`[read_*]` 等内部工具标记不会显示给学生。
- 学生首页直接加载教师已发布案例列表，点击即可推演；令牌、链接和二维码仍作为折叠的备用入口。
- 教师提交记录显示四项指标的“决策前 / 决策后”表格，金额单位为万元，未记录值明确标记。原始 JSON 制品保持完整，可追溯。
- 等待“素材已受理，任务已保存到后台”后，可以切换或关闭页面。返回教师工作台后自动选择上次案例，或发现正在生成的案例；后台任务区可切换查看其他任务。
- 上传尚未受理前关闭页面，不能保证文件传输完成。后台运行也要求本机后端服务保持运行；关闭 `start` 的服务窗口不是关闭网页。后端重启会恢复数据库中的 queued/running 任务。
- 不再以 60 次查询判定失败。网络暂断自动退避重连，后台失败则显示具体原因；不会因重连重新提交生成请求。

## 已确认原因

1. 助教代码把完整证据 `json.dumps` 拼进答案；教师记录直接 `JSON.stringify` 前后指标。不是模型返回协议解析失败。
2. 后端原本已有数据库任务和独立 asyncio worker。教师页面仍把“提交”和“最多 60 次查询”放在同一事件处理函数，重新挂载页面时不恢复监控。新增按案例查询任务接口，页面以数据库状态恢复，无需新建任务。
3. 案例修复仅传校验错误、不传上一稿；网络重试也附加错误的 JSON 纠偏说明；教师校准提示词要求“不输出 JSON”，但调用层要求 `reply` JSON。现已分别修正。

## 调用边界与预算

| 环节 | 默认最大输出 tokens | 单次请求总时限（秒） | 任务范围 |
| --- | ---: | ---: | --- |
| 案例生成与修复 | 12288 | 180 | 指定框架、3节点×3选项、完整财务校验 |
| 学生复盘生成 | 8192 | 150 | 实际策略、基础分析项、可选补充分析与改进 |
| 独立复盘审核 | 4096 | 90 | 框架、事实、优劣分析、建议；不重写报告 |
| 助教检索规划 | 2048 | 45 | 只选择必要的只读工具和可选搜索 |
| 助教解答 | 4096 | 90 | 当前问题、必要依据和引用 |
| 教师校准建议 | 4096 | 90 | 针对当前问题提出修改建议，不自动改案例 |

DeepSeek 默认 `reasoning_effort=low`，仍启用思考。默认值和可选分阶段覆盖见 `backend/.env.example`；模型名始终由实际环境配置决定。其他兼容端点不会被默认强加 DeepSeek 的 `thinking` 参数。

参考官方文档：[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[Chat Completions 参数](https://api-docs.deepseek.com/api/create-chat-completion/)。DeepSeek 官方默认思考强度为 high，项目通过环境变量显式设为 low；不使用温度参数宣称限制思考时长。

- 每个活跃环节最多一次调用层重试；网络错误保留原始提示，格式错误才附纠偏提示。
- 401、配置错误等直接失败；408、429、网络异常、服务端错误仍保留有限重试。
- 案例与学生复盘采用初稿 + 最多两次定向修复，带回上一稿；校验耗尽直接记失败，不在 worker 层把整个语义修复循环再跑三遍。
- `finish_reason=length` 即使 JSON 表面合法也不接收；若还有调用重试额度，最多放宽一次输出预算（总上限32768）。失败仍明确提示，不保存不完整稿件。
- 原始素材未截断，复盘只去除了重复的结果指标字段。复盘分析项采用动态数组：不强制固定数量或顺序，但基础框架内容、正文和综合结论必须完整；独立审核仍检查事实和因果，学生三轮决策仍不调用 AI。
- 日志包含阶段、预算、尝试次数、耗时和返回的 token 用量，不打印密钥或思考正文。

- 案例列表和任务进度的断网状态分开维护，列表恢复后自动清除警告，不会覆盖另一路的连接故障。
- 回归覆盖分阶段参数、定向修复上一稿、语义失败不重启整个流程、401单次失败、网络重试提示不污染、总超时取消、截断拒收，以及原有教师校准优先和学生决策不调用AI。

这次验证没有调用真实 DeepSeek，不宣称端到端耗时缩短某个比例。实际耗时受模型、素材长度和服务端负载影响；可用新增日志比较。浏览器自动化仍受 Codex 连接认证错误影响，未将组件/HTTP测试说成真实浏览器点击验收。
