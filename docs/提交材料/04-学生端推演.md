# 全栈技术说明 4：学生端推演

具备轻量学生账号体系（注册、登录、姓名归属、修改密码），不含 RBAC 角色权限、多租户、班级邀请、实名核验。学生注册登录后进入个人空间并选择教师已发布案例；案例令牌与链接作为可选入口保留，不再是唯一入口，二维码扫码首次未登录时转到登录页。S1 只返回题面、基准指标、节点及选项 `{key,label}`，不提前返回未选择选项的风险、摘要和结果指标。

三轮决策严格按节点顺序提交。第一轮 before 为案例基准指标，后续 before 等于上一轮 after；选项指标是目标状态快照，不作简单累加。delta 中营收为数值差，毛利率和市场份额为百分点差，现金流保存文字 from/to。

自定义决策（input_text）仍然保留，但它只作为「决策理由」保存，不产生新的财务估算。学生决策阶段不调用模型，前后指标差值由后端确定性计算。完成三轮后生成或读取复盘，维度顺序保持商科原文 5/5/4。

已验证：学生打开案例、完成一次推演、查看复盘及 390px 展示。自动化验证了 delta 数值计算，并断言决策模块不存在模型调用与降级函数。未验证：所有移动设备与微信版本兼容性（需在多机型实测）；SSE 弱网恢复的系统性压力测试（需用限速/断网工具复现）。
