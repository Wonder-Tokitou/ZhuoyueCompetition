# 全栈技术说明 5：安全、测试与运维

教师密码和模型密钥通过环境变量提供，不写入提交材料。学生端以随机发布令牌访问；错误令牌返回可读 404。教师接口校验登录后令牌，失效返回 403。

测试覆盖 seed 幂等、8 表约束、教师登录、学生案例、错误 token、delta 数值计算、决策模块无模型降级（断言 `fallback`/`decide` 不存在）、迁移幂等、Word 读取、发布门槛与版本冻结字段。最近验收结果为后端与 AI 指标 `132 passed`；前端 `34 passed`；TypeScript + Vite 构建通过。

Windows 启动脚本负责创建或复用虚拟环境、安装依赖、构建前端、运行迁移和 seed、启动 Uvicorn。全新主机一键启动尚未验证（需在干净 Windows 主机运行 `start.bat`，确认依赖安装、迁移、seed、Uvicorn 启动全流程成功）。

当前限制：SQLite 适用于 MVP；AI 能力依赖外部服务；具备轻量学生账号体系（注册、登录、姓名归属、修改密码），但不含 RBAC 角色权限、多租户、班级邀请、实名核验，也不含微信原生小程序、复杂分析看板或自研模型算法。
