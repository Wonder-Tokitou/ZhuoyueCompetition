# 全栈技术说明 2：后端与数据设计

后端按教师端与学生端拆分路由。数据层固定为 8 张业务表：framework、case、node、option_result、session、turn、message、review，不新增任务业务表。

SQLite 迁移使用 SQLAlchemy inspect 与 `ALTER TABLE`，仅增列并安全回填；迁移可重复执行。首次迁移会在备份不存在时保留数据库备份。seed 从标杆案例 JSON 读取数据，以固定学生令牌幂等写入 1 个发布案例，不调用外部模型。

一次 session 表示一次完整尝试。创建时冻结案例版本、案例快照和当前指标；turn 保存 before、after、delta 与结果来源。教师后续修改不会改变已开始 session，新 session 才读取最新版。

已验证：迁移幂等、seed 幂等、表数量为 8、delta 数值计算、案例版本与快照字段存在。未验证：大规模数据量下的 SQLite 性能（需构造万级 turn 数据后压测查询与写入耗时）。
