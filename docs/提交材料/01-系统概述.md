# 全栈技术说明 1：系统概述

case-sim 是面向商科案例教学的 Web 推演平台。教师通过密码登录，上传文本、Markdown、PDF 或 Word 素材，提交外部 AI 任务，对案例背景、困境、节点、选项和指标进行人工校准，校验通过后发布。具备轻量学生账号体系（注册、登录、姓名归属、修改密码），不含 RBAC 角色权限、多租户、班级邀请、实名核验；学生注册登录后进入个人空间，选择教师已发布案例，案例链接与二维码作为可选入口保留，按顺序完成三轮选择或自定义决策，查看指标变化与复盘。

技术栈为 FastAPI、SQLAlchemy、SQLite、React 18、TypeScript、Ant Design 5 与 Vite。前后端由同一服务提供，生产构建后 FastAPI 托管静态文件。

实际验证：后端与 AI 指标 `132 passed`；前端 `34 passed`；TypeScript + Vite 构建通过；教师与学生主流程通过人工浏览器验收；390px 页面无横向溢出；局域网访问通过。

未验证：全新 Windows 主机运行一键启动脚本（需在干净 Windows 主机运行 `start.bat` 实测）；高并发、长期稳定性和公网部署（需公网环境压测）。
