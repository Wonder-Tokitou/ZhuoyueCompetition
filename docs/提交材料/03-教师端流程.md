# 全栈技术说明 3：教师端流程

教师端使用环境变量配置的密码登录，成功后获得会话令牌；令牌失效返回 403，前端清理本地会话并返回登录页。

素材入口支持主题关键词及 txt、md、pdf、docx。Word 可抽取段落和表格；无可读文本时后端返回可读错误。案例生成通过 AI task 提交、状态查询和产出读取接口与外部 AI 或 mock 服务协作，平台本身不实现新的生成算法。

教师可人工修改标题、背景、困境、基准指标、节点和选项。保存会递增案例版本。发布前服务端校验背景、困境、三节点乘三选项、三档风险、摘要与四指标；不合规则拒绝发布。教师可查看记录并人工修正复盘。

已验证：登录、上传、任务状态、产出保存、发布主流程人工验收；docx 抽取有自动化测试。未验证：所有 PDF 版式与异常 Word 文件兼容性（需用扫描版 PDF、加密/损坏 docx 等样本实测）。
