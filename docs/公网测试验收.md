# 公网测试验收（2026-09-26）

## 已验证

- 后端/AI：115 项 pytest 通过；前端 25 项测试通过；TypeScript + Vite 构建通过。
- 8 项新增网关测试：未登录拦截、五个密钥稳定、双端共享空间、删除后立即撤销、无效配置拒绝、来源检查、退出、答疑分块格式、登录频率限制。
- 五个正式测试空间通过真实 Cloudflare HTTPS 地址检查：密钥可登录，教师端和学生端 SPA/JS 可访问，案例列表及学生列表均为空。
- 浏览器实际打开公网教师网址，输入密钥后显示空工作台；同一浏览器打开学生网址显示学生登录/注册入口。
- 临时空间通过本机 HTTP 与公网 HTTPS 分别完成：注册、上传 TXT、原件制品保存、模拟生成、发布、二维码读取、案例发现、三节点决策、模拟复盘、模拟助教、教师查看记录。
- 另一密钥访问对应案例/任务/二维码失败；同名学生账号在两个空间独立存在；实时删除密钥后该会话立即被拒绝。
- 强制关闭临时启动器后它的后台端口全部关闭；再次启动后，原密钥、已发布案例、学生账号、决策与复盘仍存在。
- 关闭临时公网启动器后，该 HTTPS 入口返回 530 不可用；正式公网入口仍返回 200 密钥登录页。停止脚本的 WhatIf 检查仅匹配本项目正式公网 Python 启动器及其虚拟环境转发进程。

真实公网全链路脚本：`backend/tests/public_http_smoke.py`；只允许对 `.test-tmp` 下的离线模拟空间运行。正式空间没有添加测试案例或账号。

## 限制与未验证项

- 模型调用使用 Mock，没有为此次验收调用付费 DeepSeek；正式启动仍使用现有本机 `.env` 的真实配置。
- 未替每一位测试者验证其实际所在地的网络/浏览器/手机相机权限。HTTPS 成功不代表所有运营商网络都保证可达。
- Quick Tunnel 是测试用途，无可用性保证，重启网址可能变化；密钥及数据不随网址变化而重建。
- 本轮未做公开互联网大规模负载/渗透测试，不应将测试密钥公开发布，也不要用于真实敏感数据。
- 保留既有前端大包警告和 Starlette/httpx 弃用提示；不阻碍本轮功能验收。
