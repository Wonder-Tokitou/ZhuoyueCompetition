# 学生空间架构与联调（2026-09-25）

## 当前验收主线

按用户最新要求，优先跑通：学生自行注册 / 登录 → 填写并保存姓名 → 完成案例作答 → 教师读取。
不要求教师事先创建账号，不引入实名核验、审批、班级邀请、多租户或复杂权限配置。
后台已有密码哈希和作答归属检查保留，无需额外配置。

仅修改 `本地化构建`，未修改原始 `case-sim`，未读取或改写真实模型密钥。

## 本地使用

1. 手动重启本目录 `start.bat`，应用数据库增量迁移和最新前端。
2. 打开 `/student/login`，选择“首次使用 · 注册”，填写姓名、账号和密码。
   账号支持英文、数字、点、短横线和下划线；密码至少 8 位。
3. 注册后直接进入个人空间，点击“案例推演”，选择教师已发布的案例。
4. 完成三轮选择，作答自动保存；推演完成后可打开 AI 复盘。
5. 教师登录后，“学生管理”可看到新注册的姓名和账号；“案例记录”按案例 → 学生 → 推演记录展开查看。
6. 学生可从“我的提交记录”恢复进度或查看复盘，从“个人与账号信息”查看姓名和修改密码。

案例链接只选择案例；首次扫码未登录时转到登录页，登录后返回原案例。
旧匿名数据不删除，也不按相同姓名自动认领。教师仍可查看历史匿名记录。

## 推演、复盘与答疑边界

- 推演：冻结教师版本，直接返回所选策略的已发布结果，不调用 AI 生成财务结果。
- 复盘：作答完成后独立异步任务生成，结合原始素材、教师版本、实际策略和计算结果，经过结构检查和独立审核。
- 答疑：独立侧栏，读取所选会话的已保存案例及本人作答；不提供未提交选项的答案，不改写结果。
- 教师校准：复盘修改进入数据库和 `teacher_review_final` 制品，已有复盘不会被任务重跑覆盖。

答疑规划与回答请求均使用 `reasoning_effort=low`；DeepSeek 使用其 OpenAI 兼容接口的 `thinking.type=enabled`。
参考：https://api-docs.deepseek.com/guides/thinking_mode/

## 可选网页搜索

在 `backend/.env` 自行配置 `TAVILY_API_KEY`；未配置时仍可使用本地资料答疑，并明确提示没有网页结果。
搜索适配器默认使用 Tavily 的 basic 搜索，每次答疑最多一次查询、三条结果、每条 1500 字符；来源受 `TUTOR_SEARCH_DOMAINS` 白名单约束。
网页资料标记为外部补充，附 URL 和检索时间，不作为教师发布事实。
这次测试使用模拟接口，没有调用真实搜索服务或产生搜索费用。
参考：https://docs.tavily.com/documentation/api-reference/endpoint/search

## 复盘超时修复

已复现：页面固定查询 60 次后报“生成超时”，但后台仍在执行生成、独立检查及修复。
现在只要服务端返回 pending/running 就继续查询；临时网络错误自动退避重连，明确区分连接故障与任务失败。
切换案例清空旧内容，取消前端请求并忽略旧响应；离开页面不取消数据库里的任务。
不再显示没有计算依据的 70% 进度。
复盘证据去除了重复的一份原始素材；可选 `LLM_READ_TIMEOUT=120` 调整单次读取超时（10–300 秒），不改动现有 .env。

## 数据与文件

新增 `student_account`、`student_login` 表，以及 `session.student_id`。
迁移只追加列，SQLite 备份针对实际 `DATABASE_URL` 指定文件生成 `.bak-v5`，不碰默认路径下的其他数据库。

新制品目录：

```text
backend/data/artifacts/cases/<case_id>/
  students/<student_id>/submissions/<session_id>/
    session_case_snapshot-*.json
    student_submission-*.json
    tutor_answer-*.json
    teacher_review_final-*.json
    tasks/<task_id>/...
```

文件系统使用稳定 ID 防止重名和改名导致路径冲突；教师页面以姓名展示目录。
旧制品通过数据库保存的原路径继续读取，不批量搬迁、不删除。
每轮提交保存一次制品；教师版完整快照不会作为学生前端 JSON 下发。

## 接口

- `POST /api/student/register`：姓名、账号、密码；注册并登录。
- `POST /api/student/login`、`POST /api/student/logout`。
- `GET /api/student/me`、`POST /api/student/password`。
- `GET /api/student/cases`：教师已发布案例列表。
- `GET /api/student/records`：本人历史作答和已保存复盘。
- `GET/POST /api/teacher/students`、`PATCH /api/teacher/students/{id}`。
- 原 `/api/play/...` 路由保留，携带学生登录 Authorization 头。
- 新增 `/api/play/{token}/sessions/{id}/messages` 读取本人答疑历史。
