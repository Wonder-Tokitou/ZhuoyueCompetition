# 本地实时运行日志

双击根目录 start.bat：原窗口显示依赖检查、前端构建和服务器输出；
服务器启动时另开一个实时日志控制台，教师端与学生端共用（它们由同一后端服务）。学生端常驻入口是 `/student`；二维码仍指向 `/student/{student_token}`，两者使用同一套学生端页面与日志链路。
无需分别启动两台服务器。关闭日志窗口不会停止服务器；原启动窗口 Ctrl+C 停服。
如端口已占用，新服务会报错，请先关闭自己之前启动的服务，不要连续双击启动。

日志位于项目根目录 logs/runtime-日期-时间-PID.log，UTF-8 编码。
同一运行文件达到 10 MiB 会轮转，最多保留 5 个轮转备份；
不同启动产生的历史日志不自动删除，请自行归档或清理。logs 已被 Git 忽略。
可以随时重新打开查看器（在项目根目录运行）：

```powershell
.\.venv\Scripts\python.exe scripts\watch_logs.py "logs\具体的日志文件.log"
```

## 能看到什么

- 教师上传：文件名、字节数、解析字符数；“已接收”不代表解析/落库成功，
  只有“上传及入库成功”才表示已保存、已入队。解析失败会显示 HTTP 状态和具体原因。
- AI 工作流：task ID、案例/会话 ID、阶段、生成或修复轮次、校验问题、重试、产物路径。
- 模型请求：模型名、主机、调用编号、耗时、输入/输出字符数、JSON 输出摘要；
  HTTP 错误、JSON 解析失败、缺字段和网络异常分别显示。
- 教师校准/发布：保存成功、修改字段名、版本及案例 ID。
- 学生：决策节点、选项、执行来源、计算后的指标、下一节点、复盘任务；
  答疑流的开始、结束、字符数、错误及保存失败。
- 请求：request ID、路由模板、HTTP 状态和耗时。登录令牌所在的查询参数不记入日志。

日志展示实际程序调用链，不是大模型内部思考过程。
学生决策统一使用教师发布的结果，不调用模型；文字作为决策理由保存。
答疑会记录 Agent 检索规划、只读工具名称、文件制品 ID 和依据校验。
复盘在推演完成后调用模型，记录证据准备、生成、结构校验、独立审核与修复。

## 需要看模型输出正文时

在 backend/.env 增加下面配置并重启：

```dotenv
LOG_AI_CONTENT=1
```

默认 0，只输出字段/数量等摘要。启用后 JSON 模型调用最多显示 2000 字符脱敏预览，
流式答疑仍仅记录输出长度。完整成功任务输出可通过教师任务接口/产物文件查看。
预览可能含教学材料或个人信息，只应在使用测试素材的本机调试时开启；
分享日志前请再次检查。日志不保存完整提示词/上传正文/学生姓名/请求体，
密钥与令牌会脱敏；不要把日志放到前端静态目录。

浏览器内部 JavaScript 错误或请求根本未到达后端的网络错误仍需查看浏览器 F12 Console/Network，
不能把“后端没有日志”当作成功。依赖安装或前端构建失败看原启动窗口，
独立日志窗口在服务器阶段才打开。

## 离线验证

```powershell
.\.venv\Scripts\python.exe -m unittest backend.tests.test_runtime_logging -v
.\.venv\Scripts\python.exe -m unittest backend.tests.test_logging_http -v
```

HTTP 测试必须独立运行：使用临时数据库、临时产物和日志，模拟模型输出，不调用 DeepSeek。
